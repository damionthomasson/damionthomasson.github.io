Overview

I designed and built a portfolio for a digital illustrator, with one goal: let the artwork speak for itself. The interface is deliberately minimal and content-first, so high-resolution pieces stay the focus on every screen size.

The site is written in plain HTML, CSS and JavaScript with no external libraries, keeping it lightweight and quick to load.

What I built

Responsive gallery grid

A CSS Grid layout with auto-fill that scales smoothly from 4K monitors down to phones.

Custom lightbox

A vanilla JavaScript lightbox for distraction-free, full-screen viewing of each piece.

Commission enquiries

Email and Discord community links make it easy for clients to get in touch about commissions.

Highlights

Performance

Zero dependencies keeps page weight low and load times fast.

User experience

Single-page layout with smooth in-page navigation between sections.

SEO & accessibility

Semantic HTML structure that search engines and assistive technology can read.
