Beatrush

A broadcast-style radio terminal that turns live track data into a reactive, real-time visual experience.

Role
Design & full-stack development
Type
Web application
Stack

Year

Overview

Beatrush is a broadcast interface for an online radio station, bringing gaming-inspired visuals together with the reliability expected of a live broadcast.

Built with Laravel and Inertia.js on a Vue 3 front-end, it keeps track metadata, listener profiles and the interface itself in sync in real time — without full page reloads.

What I built

Live track metadata

High-frequency track polling with server-side throttling keeps now-playing information current without overloading the API.

Seamless profile loading

Listener profiles load asynchronously via Inertia.js, so navigation never resets the page or interrupts playback.

Reactive visuals

Interface brightness and colour palette respond to the BPM and energy of the current track.

Highlights

Performance

State updates are reflected in under 50 ms, so listener interactions feel instant.

Real-time sync

PocketBase real-time subscriptions push changes to every connected client.

Integration

Custom API integration connects the station's broadcast data to the UI.
