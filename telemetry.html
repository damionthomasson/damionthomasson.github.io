Truck Systems

A real-time telemetry HUD for truck simulators, built with a Rust backend and a Vue 3 overlay.

Overview

Truck Systems is a desktop heads-up display that reads live telemetry from a truck simulator and presents it in a clean overlay.

A Rust backend, packaged with Tauri, reads game data through Windows shared memory and streams it to a Vue 3 + TypeScript front-end at 30 Hz or more.

What I built

Low-latency streaming

Reads the game's memory-mapped telemetry via the Win32 OpenFileMappingW API at 30 Hz+.

Adaptive tachometer

A custom SVG rev counter that rescales automatically to each engine's RPM range.

Automatic SDK handshake

A background thread uses Enigo to dismiss the SDK prompt automatically on start-up.

Key challenge

Running alongside an elevated process

The game runs with elevated privileges, which normally blocks a standard user-space app from reading its memory map. I worked through Windows integrity levels and security attributes and implemented a non-inherited handle strategy, so telemetry flows reliably without requiring users to run the HUD as Administrator.
